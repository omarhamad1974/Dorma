# Media library

Files in these folders appear in the studio's **Library** after the site redeploys (about two minutes
after a commit to `main`). Each folder is a category:

| Folder | Category |
| --- | --- |
| `brand` | Brand & Identity |
| `content` | Photo & Video |
| `events` | Events & Activations |
| `exhibitions` | Exhibitions & Booths |
| `digital` | Digital & Social |
| `print` | Print & Packaging |
| `signage` | Signage & Fabrication |
| `gifts` | Gifts & Displays |
| `backgrounds` | Backgrounds & Textures |
| `articles` | Articles & Guides (PDF) |

Images: jpg, png, webp, gif, avif, svg. Video: mp4, webm. Articles: pdf.
GitHub's web upload takes files up to 25 MB; compress videos first (under 10 MB is a good target).

To add files: open a folder on GitHub → **Add file → Upload files** → drop them in → **Commit changes**.
Titles, descriptions, tags and categories are then edited in the studio. Renaming or moving a file on
GitHub makes it a new file, so do that before using it on pages.
