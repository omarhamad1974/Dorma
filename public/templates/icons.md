# Dorma icons

Icons can be used in flows, buttons and text items. They draw with the current text colour.

How to use this file:

1. Write one block per icon. Start every icon with a line of three dashes: ---
2. Put the SVG code between two lines of three backticks (```), as below.
3. In the studio, open Content › Import, choose "Icons", and pick this file.
   Scripts, links and styles inside the SVG are removed automatically.

Everything above the first --- line is ignored.
