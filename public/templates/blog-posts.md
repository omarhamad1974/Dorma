# Dorma blog posts

How to use this file:

1. Write one block per post. Start every post with a line of three dashes: ---
2. Fill in the lines you need. Leave a line empty, or delete it, to skip it.
3. In the studio, open Content › Import, choose "Blog posts", and pick this file.
   You will see every post before anything changes.

What each line means:

- Title: the post's heading. Title (Arabic): only if the site shows Arabic.
- Address: the end of the post's link (#post/your-address). Leave empty to make it from the title.
- Date: written as 2026-11-25. Empty uses today.
- Published: yes to show it to visitors, no to keep it as a draft (the default).
- Category: a Library category name, such as Exhibitions & Booths. A new name adds a category.
- Author: empty uses the brand name.
- Tags: separated by commas.
- Cover: a picture from the Library (file path, name as shown in the Library, or https:// link).
- Summary: the short text shown in the list of posts.
- Body: the whole post. Write it on the lines after "Body:" (it runs to the next ---).
  Empty line = new paragraph · ## Heading · - list item · > quote · **bold** · *italic* · [text](https://…)
  An image from the Library on its own line: [[library-id|caption]]
  For Arabic, add "Body (Arabic):" on its own line after the English text.
  Inside Body, never use a line of three dashes: it starts the next post.

Everything above the first --- line is ignored, so you can keep these notes.
